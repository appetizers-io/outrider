Maintainers are the only people with write access to this repository. Only
they can:

- approve and merge pull requests: every change needs a code owner's review
  (see [`.github/CODEOWNERS`](.github/CODEOWNERS))
- approve workflow runs for pull requests from outside contributors
- run workflows by hand, including the release (Actions → Release, `main` only,
  in the `release` environment)

To add a maintainer, give them write access, add them here and to
`.github/CODEOWNERS`, and add them as a reviewer of the `release` environment.
